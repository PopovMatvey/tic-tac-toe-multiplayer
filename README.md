# Крестики-нолики

Мультиплеер: регистрация, партии до трёх побед, поле `DESK_SIZE`, два инстанса сервера. Ход, принятый на одном процессе, доходит до соперника на другом через Kafka.

Запуск и описание частей: [docs/README.md](docs/README.md).

```text
браузер -> nginx -> app1 или app2 -> Postgres
                         |    |
                         +----+-> Kafka -> оба инстанса -> WebSocket своего игрока
```
