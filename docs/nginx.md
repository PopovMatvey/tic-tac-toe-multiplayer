# Nginx

Конфиг: `nginx/nginx.conf`. Образ собирает клиент и раздаёт его с корня.

Порт снаружи: `2101`.

Upstream `app` — `app1:3000` и `app2:3000`, по кругу, без sticky-сессий. Так `GET /api/health` и `POST /api/users` могут попасть не на тот процесс, где открыт сокет.

`/api/` проксируется как обычный HTTP.

`/socket.io/` проксируется с `Upgrade` и `Connection: upgrade`. Одно WebSocket-соединение остаётся на том инстансе, который принял TCP. Клиент не использует long-polling Socket.IO: иначе следующие poll-запросы ушли бы на другой процесс, где этого сокета нет.

`/` отдаёт собранный React. Неизвестные пути возвращают `index.html`, маршруты клиентские.
